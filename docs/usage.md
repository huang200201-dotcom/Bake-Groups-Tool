# 安装与使用

## 环境

Windows x64，Maya 2022、2023、2024、2025、2026 或 2027；Maya 2022 须使用 Python 3。不需要账号、联网激活或许可证。

## 安装或迁移

从官方 [Releases](https://github.com/huang200201-dotcom/Bake-Groups-Tool/releases) 下载完整 Windows 安装包，解压后将 `安装到Maya.py` 拖到 Maya 视口。若此进程已加载插件原生模块，安装器会要求先重启 Maya；重启后先安装，再打开插件。

开源版使用平铺的 `Bake_Groups` 安装目录。安装器能整体替换旧 `versions/` 结构，不会因为旧版本号大于开源版本号而拒绝迁移。请单独保存安装目录内的个人代码修改。插件目录之外的 Maya 场景、许可证记录和其他脚本不属于安装器的清理范围。

源码 ZIP 不含编译好的原生模块，不能代替完整 Windows 安装包；开发者请按 `building.md` 构建。

## 自动与手动更新

1.0.0 没有内置更新功能，须先手动安装一次 1.0.1。后续版本通过公开 GitHub Releases 更新，无需 GitHub 登录、令牌或许可证。

- “自动更新”默认勾选，可以取消。启用时，每次 Maya 进程自动检查一次新版，并在插件空闲时应用更新。取消勾选会请求停止正在进行的自动检查或下载；已经暂存的更新会保留。
- “手动更新”用于手动检查、下载和应用新版；“访问仓库网站”打开项目仓库首页。
- Python 变化可在空闲时热重载。插件任务运行期间不会强行重载。
- 如果已加载的原生模块需要改变，只暂存更新并提示重启。保存自己的工作，重启 Maya，再打开插件即可应用；插件不会自动重启 Maya。
- 断网或 GitHub 请求失败时可继续使用当前安装。需要离线安装时，仍可使用完整 ZIP 和拖放安装器。

更新会替换插件代码和资源，请将本地代码修改另行保存。Git 源码检出目录不执行自动更新。更新暂存与恢复文件保存在安装目录旁的 `Bake_Groups.update` 中；发生错误时先保留它，并查看 Script Editor 的提示。

## 工作流

- **自动分组**：登记资产的 HP / LP，选择分组策略，运行分析，再检查当前章节的最终分组。
- **资产任务**：组织现有资产任务和章节，按需要执行批量工作。
- 在最终检查中设置高模细分和独立岛 ID，需要时生成或维护 Cage，导出当前章节或指定模型。
- 导出在副本上处理三角化、颜色和合并，结束后保留操作前的低模显隐、选择与平滑预览。

手动修正页面已经移除。已有场景中自动流程使用的分组数据继续保留，不需要为了升级重新创建资产。

## 故障定位

- 提示缺少原生模块：确认下载的是 Windows 完整包，且存在 `Bake_Groups/bin/<Maya年份>/bg_math_core.pyd`。
- 提示原生模块来自另一安装：重启 Maya，确保工具架按钮指向当前安装目录。
- 导出失败：查看 Script Editor 的具体错误；原有目标文件在新文件成功写入前会保留。
- 问题报告请提供 Maya 版本、插件版本、可复现步骤和最小测试场景。
