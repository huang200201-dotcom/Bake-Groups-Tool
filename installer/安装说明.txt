Bake Master 1.3.15
完整便携安装包

支持：Maya 2022、2023、2024、2025、2026、2027（Windows 64 位）
Maya 2022 必须使用 Python 3 模式，不支持 Python 2 模式。

推荐安装方式
==============================
1. 解压整个 ZIP，不能只从压缩包中单独打开脚本。
2. 启动 Maya。
3. 把“安装到Maya.py”直接拖进 Maya 的模型视口。
4. 安装程序会复制插件、在当前工具架创建 BAKE GROUPS 按钮，并立即打开插件。

Maya 未启动时安装
==============================
1. 双击“安装_Bake_Groups.bat”。
2. 启动或重启 Maya。
3. 若工具架没有按钮，把“创建工具架按钮.py”拖进 Maya 视口。

安装位置
==============================
当前 Windows 用户的：
Documents\maya\scripts\Bake_Groups

注意事项
==============================
- 必须保留 Bake_Groups 文件夹的完整结构。
- Maya 2022 请使用默认的 Python 3 模式启动；不要使用 -pythonver 2。
- 不要把插件直接放在中文包目录中运行，应先执行安装。
- 插件启动后会自动检查 GitHub 稳定版更新；下载安装前会征求确认。
- 安装新版时可以直接覆盖旧版；建议先关闭 Bake Master 窗口。
- 若拖拽安装提示核心文件正在占用，请完全关闭 Maya，再双击“安装_Bake_Groups.bat”。
- “卸载_Bake_Groups.bat”会删除插件目录，但不会自动删除 Maya 工具架按钮。

版本内容
==============================
- LP 匹配复用原生点云索引，大量高低模候选时明显加速。
- 减少重复启动、场景扫描、预览颜色和导出阶段的无效开销。
- 修复薄片、交叉长条、多壳低模和凹多边形的匹配误差。
- 修复 Maya 外部撤销/重做、打开失败和保存颜色预览时的状态问题。
- 更新清单增加独立 Ed25519 签名，下载和解压限制严格生效。
