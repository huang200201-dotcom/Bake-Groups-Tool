Bake Master 1.0.0 — 开源版

支持 Maya 2022–2027，Windows x64。Maya 2022 请使用 Python 3 模式。

1. 解压完整 ZIP，保持“安装到Maya.py”、Bake_Groups 和 SHA256.txt 相邻。
2. 如果当前 Maya 已打开过 Bake Master，请先重启 Maya。
3. 重启后先安装，再打开插件：将“安装到Maya.py”拖入 Maya 视口。
4. 点击当前工具架的 BAKE MASTER 按钮启动。

安装位置为当前 Maya 用户 scripts 目录下的 Bake_Groups。
支持从旧 1.x 加密版的 versions 布局直接升级到开源 1.0.0；不按版本号大小拒绝升级。
安装失败会自动恢复原插件目录。安装器不打开或保存场景，不访问用户许可记录。
若误将 .ma/.mb 场景放在旧 Bake_Groups 安装目录中，安装器会拒绝覆盖；请先移到项目目录。
已有原生模块不能在同一次 Maya 进程中安全替换，因此要求重启后先安装。

此版本无需激活、令牌或联网授权。后续版本从 GitHub Releases 下载完整 ZIP 安装。
SHA256.txt 用于检查包完整性；请从项目官方 Release 获取发行包。
源码和构建说明见 README.md、SOURCE_CODE.md，以及对应 GitHub 标签。
